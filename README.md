# 入学・卒業・入社年 早見表

生年月日を入れると、幼稚園（保育園）から大学・大学院までの入学年と卒業年、新卒入社の年が一覧でわかるツールです。履歴書の学歴欄を書くときに使えます。

公開URL：https://novalis-lab.github.io/school-years/

## できること

- 生年月日（年・月・日）を選ぶと、すぐに表が変わる
- 最終学歴：中学校／高校／専門学校（2年）／短大（2年）／大学（4年）／大学（6年：医学部・薬学部など）／大学院 修士／大学院 博士
- 浪人した年数（0〜5年）：高校卒業後の学校の入学を遅らせる（最終学歴が中学校・高校のときは使わない）
- 留年した年数（0〜5年）：最終学歴の卒業を遅らせる
- 幼稚園（保育園）：3年保育／2年保育／表示しない
- 「学校名／入学／卒業」の表と、最後の行に「新卒入社」を表示
- 西暦と和暦を両方表示（和暦は月まで見て判定）。まだ来ていない年月には「予定」マーク
- 結果をまとめてコピー（両方／西暦だけ／和暦だけ を選べる。履歴書の順番で1行ずつ）

## 計算のきまり

- 4月2日生まれ〜翌年4月1日生まれが同じ学年
- 1月1日〜4月1日生まれ（早生まれ。4月1日生まれも含む）：小学校入学＝生まれた年＋6年の4月
- 4月2日〜12月31日生まれ：小学校入学＝生まれた年＋7年の4月
- 入学は4月、卒業は3月。小学校6年・中学校3年・高校3年
- 新卒入社は、最終学歴を卒業した年の4月
- 和暦：令和は2019年5月1日から、平成は1989年1月8日から（2019年3月・4月は平成31年）

例：2000年4月1日生まれ → 小学校入学 2006年4月／2000年4月2日生まれ → 2007年4月／1990年5月10日生まれ・大学（4年） → 大学卒業 2013年3月、新卒入社 2013年4月

## 保存について

選んだ生年月日・学歴などは、この端末のブラウザの中だけに保存します（次に開いたとき用）。どこにも送信しません。

## 広告を入れるとき

`index.html` の `<aside class="ad-slot">` の中に広告のコードを貼り、「広告スペース」の文字を消してください。

## そのほか

- デザインは「日付計算」（Novalis-lab/date-calc）と同じ形で、差し色だけ黄色（#f6c453）にしています
- フォント・角の丸み・アイコンは、トップページ（novalis-lab.github.io）の共通ファイルを読み込んでいます
- 外部サービス・ログイン・APIキー・ライブラリは使っていません
